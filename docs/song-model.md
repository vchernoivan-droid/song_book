# Модель песни

Код: `mobile-app/lib/services/song_parser.dart` (part-файлы:
`_lexer`, `_parse`, `_render`, `_propagate`).
Тесты: `mobile-app/test/song_parser_test.dart`.

## Слои

Текст «аккорды над словами» → `parseSong` → `ParsedSong` → `renderSong` →
канонический текст.

`ParsedSong`:

- `sections` — секции;
- `tonic`/`tonicName` — тоника: питч и написание первого аккорда песни.
  `Chord` хранит смещения от тоники; транспонирование — смена тоники
  (`transposed`), имена аккордов считает рендер.

`Section`: `title` (заголовок `[...]` или `Куплет:`), `kind`
(verse/chorus/bridge/intro/outro/solo/unknown — по ключевым словам
заголовка), `lines`.

`Line`: `tokens` + `stanzaStart` — перед строкой в исходнике стояла
пустая (граница строфы внутри секции). Это только форматирование:
номера строки не занимает, локатор и `tops` не видят.

Токены:

- `SyllableToken` — слог: `text` (ведущий дефис дефисной части — в
  тексте), `dash` (none/right — начало слова, both/left —
  продолжение), `chord` — первый аккорд слога. Пустой слог
  (`text == ''`) — позиция «аккорд над пробелом».
- `ChordToken` — доп. смена аккорда на предыдущем слоге;
  `endOfLine: true` — аккорд за концом слов (в конце списка токенов).
- `InlineToken` — пометка аккордной строки: `~` (glued — приклеена к
  предыдущему аккорду) или «2x»/«// …» (хвост строки).
- `AnnotationToken` — хвост строки текста («(2 раза)»).
- `RawToken` — строка табулатуры.

`Line.isProgression` — строка без слогов (только аккорды/пометки).

## Парсинг

Текст режется на блоки пустыми строками. Первый аккорд песни — тоника.

- Блок с заголовком → новая секция. Заголовок: `[...]` — всегда;
  `Слово:` — только если внутри ключевое слово типа.
- Блок без заголовка — **строфа предыдущей секции**: строки
  добавляются в неё, первой ставится `stanzaStart: true`. До первой
  секции с заголовком такой блок — самостоятельная unknown-секция.
- Пара «строка аккордов + строка текста» склеивается в одну `Line`:
  аккорд привязывается к слогу пересечением колонок; второй аккорд
  слога — `ChordToken` сразу за ним; аккорд за последним словом —
  `ChordToken(endOfLine)`; аккорд над пробелом — пустой слог.
- Строка только из аккордов — прогрессия. Строка табов — `RawToken`.
- Слова режутся на слоги фонетически (`syllable_split.dart`),
  дефисные части — по дефисам исходника.

## Рендер

Канонический текст: заголовок в `[...]`, между секциями пустая строка,
перед `stanzaStart` — пустая строка. Колонки не хранятся: аккордная
строка собирается заново — внутри слова аккорды прижаты к слогам
(имя не влезает — стык растягивается дефисом), между словами резерв
под #/b (вёрстка не переезжает при транспонировании).

## Размножение аккордов (propagateChords)

Кнопка «Размножить аккорды» в редакторе:
`renderSong(propagateChords(parseSong(text)))`.

Типы: verse, chorus, bridge. Шаблон типа — первая секция типа, где
есть слог с аккордом (обычно первый куплет/припев). Применяется ко
всем следующим секциям того же типа, строка i → строка i. Строка
шаблона без аккордов — целевую не трогает. Прогрессии и табы — не
трогает.

Сопоставление внутри строки — по «поющимся» слогам: непустой текст,
в котором есть буквы/цифры. Пустые слоги-зазоры и пунктуальные куски
(тире) не считаются и индекс не сдвигают.

Слой шаблонной строки:

- слог №i → первый аккорд + доп. смены (`ChordToken`) и `~` (glued
  `InlineToken`), идущие за слогом до следующего слога;
- зазорный аккорд (над пробелом) → позиция «после слога №i»
  (−1 = перед первым);
- хвостовые аккорды (`endOfLine`) → в конец целевой строки.

Перенос всегда по позиции слога, без проверки границ слов. Целевая
строка зеркалит шаблон: собственные аккорды слогов/зазоров/хвоста
заменяются; безаккордные пустые слоги (растяжки), пунктуация,
аннотации и «2x»/«// …» сохраняются как есть.

Слогов в целевой строке меньше — аккорды без пары пропускаются
(мелодически совпадающие строки обычно равны по слогам). Идемпотентно,
в том числе через полный parse→render→parse.

## Ограничения

- строки сверх длины шаблона не трогаются;
- intro/outro/solo не размножаются;
- пометки «2x»/комментарии и аннотации строк не переносятся.
